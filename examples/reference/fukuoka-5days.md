# 福岡、日本 5 天 4 夜行程 — 2027 年 3 月下旬（春櫻）

> 為「自己一個人 / 5 萬 TWD 以下 / 大眾運輸 / 美食・文化歷史・自然・購物」優化。每筆 transit / hours / fare 都用網路資料驗證並附 URL。

## Trip Overview

- **Origin**：台北，台灣
- **Destination**：福岡，日本（九州）
- **Dates**：2027/03/20（六）- 03/24（三），含抵達 / 離開當天
- **Duration**：5 天 4 夜
- **Travelers**：1 成人（自己一個人）
- **Budget**：NT$50,000 以內（1 人 5 天全包）
- **Trip type**：國際
- **Transport mode**：大眾運輸（JR 筑肥線 / 西鐵天神大牟田線 / 福岡市地下鐵 / 糸島巴士）
- **Pace**：中等
- **Stated preferences (Step 2a)**：trip style = 美食 + 文化歷史 + 自然風景 + 購物；budget = mid-range；companions = solo；must-avoid = 人多
- **Stamina**：中等（5–10 km / 天）
- **Hotel**：Toyoko Inn Hakata Ekimae（步行 3 分到博多站）

- [ ] Currency exchanged：建議備 ¥20,000–30,000 現金（屋台 / 小店用）
- [ ] No vaccinations required（台灣 → 日本）
- [ ] Embassy contact saved offline：駐大阪辦事處（福岡轄區） +81-6-6443-8481
- [ ] Emergency numbers saved：警察 110、消防 119
- [ ] 旅行保險號碼 saved offline
- [ ] 緊急聯絡人 shared with family
- [ ] Passport photocopy stored separately

### Trip-specific notes

- **簽證**：免簽 90 天（Taiwan passport）
- **時差**：UTC+9，比台灣快 1 小時
- **氣候**：3 月底白天 10–17°C / 早晚 5–9°C
- **旅遊警示**：低風險（standard precautions）
- **Tipping**：無小費文化，屋台別留硬幣
- **鞋子**：寺廟 / 傳統餐廳需脫鞋，建議穿好穿脫的鞋
- **Toilets**：公共廁多有免治，沖水鈕在右側
- **Common scams**：少見，博多 / 中洲人多注意扒手
- **Emergency**：警察 110、消防 119、駐大阪辦事處 +81-6-6443-8481

## 氣候資訊 / Climate Information

### Weather summary（2027/03/20–03/24，預估）

- **溫度**：白天 12–17°C / 早晚 5–9°C
- **降雨**：機率 20–30%，多雲時晴
- **櫻花預測**：3/20 開花、3/29 滿開（依 2026 年實況外推 2027）
  - 你行程期間正是早開 → 接近滿開
  - 推薦賞櫻點：舞鶴公園（Day 5）、太宰府參道（Day 2）
- **Source**：
  - [Japan Cherry Blossom Forecast 2027](https://selfguidejapan.com/blog/japan-cherry-blossom-forecast-2027)
  - [Kyushu Cherry Blossom Dates](https://kyushujourneys.com/kyushu-cherry-blossom-dates-2027/)

### Clothing recommendations

- **外套**：輕羽絨 / fleece + 防風薄外套（早晚冷）
- **白天**：長袖 + 薄襯衫或針織
- **褲子**：牛仔褲 / 長褲（早晚禦寒）
- **鞋子**：好走的步行鞋（每日 8–12 km），避免新鞋（磨腳）
- **配件**：折傘、圍巾、墨鏡
- **室內**：商家暖氣，內搭短袖即可
- **雨天備案**：每個 day 都列 1 個室內替代點（見各 day notes）

### 11. 票券 / Pass 與物流

#### 票券

- **西鐵太宰府柳川 Excursion Pass**（¥2,000 / 2 日）：含西鐵天神大牟田線 太宰府 ↔ 柳川來回 + 船票折扣 [Source](https://www.ensen24.jp/kippu/en/dazaifu-yanagawa02/)

- **Suica / Pasmo IC card**：含 ¥500 押金（可退），加值後可用於所有大眾運輸

#### 行前物流

- **國際機票**：建議 2–3 個月前鎖價（春櫻旺季 TPE-FUK 經濟艙 NT$10,000–15,000）
- **飯店**：1–2 個月前訂 Toyoko Inn
- **eSIM**：1 週前訂（Ubigi 或 Airalo 3–5 GB / 5 天 約 NT$200）
- **Travel insurance**：含醫療 + trip cancellation，出發前 2 週內買
- **換匯**：台灣銀行臨櫃換，建議 ¥20,000–30,000 現金（屋台 / 小店用）
- **疫苗**：無要求
- **插座**：Type A（與台灣同型，不需轉接頭）
- **駐福岡辦事處**：駐大阪辦事處（福岡轄區）+81-6-6443-8481
